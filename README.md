# Pablol Path

Progress ABL Open Lib for path utility programs.

## Vision

This lib is intended to provide a set of utility programs for path manipulation
and management in Progress ABL (Advanced Business Language). The goal is to
simplify common tasks related to file and directory paths, making it easier for
developers to work with file systems in their applications.

## Compilation

Follow these steps to compile the library:
1. Ensure you have Progress ABL installed and properly configured on your system.
2. Open your procedure editor.
3. Add the `lib` directory to your procedure editor propath.
4. Run the application compiler to compile the source code files located in the `lib` directory.
